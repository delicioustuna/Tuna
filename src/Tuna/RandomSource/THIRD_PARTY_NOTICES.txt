Tuna random sources: references and license notices
======================================================

The generator implementation code in this directory was written for
Tuna from mathematical algorithm descriptions. It does not include
copied or translated third-party implementation code. PCG seed expansion
uses the .NET SHA-256 API and an Tuna-specific input format; it does
not reproduce NumPy's SeedSequence implementation.

Reference implementations were consulted during algorithm selection and
are used to identify the algorithms and verify numeric outputs. Their
copyright notices and license texts are reproduced below for provenance.
This does not change the MIT license of the Tuna implementation.
These documents are included in binary distributions for provenance.
